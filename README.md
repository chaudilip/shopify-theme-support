# shopify-theme-support

Public documentation and support tracker for Shopify themes by Syrek Studio.

The published site lives at
<https://chaudilip.github.io/shopify-theme-support/>, built from this branch by
GitHub Pages.

Each theme has its own folder:

- `scullery/` — Scullery
  - `index.md` — landing page
  - `setup.md` — merchant setup guide
  - `custom-data.md` — metafield / custom data guide
  - `support.md` — how to get help

Theme source is kept in a separate private repository. Nothing in this repo is
part of the theme package that merchants install.
